
# NSCLC Clinical SAS Programming Project

## 1. Project Overview
This project demonstrates clinical trial data programming using SAS for a simulated Phase III Non-Small Cell Lung Cancer (NSCLC) clinical study.

## 2. Study Information
- Study Type: Phase III Clinical Trial
- Therapeutic Area: Oncology
- Indication: Non-Small Cell Lung Cancer
- Programming Language: SAS 9.4
- Data Standard: CDISC

## 3. Project Objectives
- Raw clinical data preparation
- SDTM dataset development
- ADaM dataset development
- Clinical data analysis
- Tables, Listings and Figures generation
- Quality Control and Validation

## 4. SDTM Domains
- DM - Demographics
- AE - Adverse Events
- EX - Exposure
- LB - Laboratory Tests

## 5. ADaM Datasets
- ADSL - Subject-Level Analysis Dataset
- ADAE - Adverse Events Analysis Dataset

## 6. SAS Programming Techniques
- DATA Step
- PROC SORT
- PROC SQL
- BY-Group Processing
- FIRST. and LAST. Processing
- RETAIN Statement
- Arrays
- SAS Macros

## 7. Deliverables
- SDTM datasets
- ADaM datasets
- Statistical summaries
- TLF outputs
- QC reports

## 8. Disclaimer
All clinical data used in this project are synthetic and created for educational and portfolio purposes only.
